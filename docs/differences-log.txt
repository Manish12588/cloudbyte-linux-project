Author: Manish Kumar

1. DEFAULT USER

Observation: The default login user on EC2 is ec2-user, with home directory
/home/ec2-user. On the local VM the equivalent was vagrant (/home/vagrant) on
Vagrant, or your Mac username on Lima.

Implication: Every absolute path in the cron entries now begins /home/ec2-user/...
instead of /vagrant/... or /host/.... Any script or scheduled job that hard-coded
the old mount path has to be re-pathed for the host it runs on. The onboarded users
(alice, bob, and the rest) are unaffected, because onboard-user.sh creates them
independently of whoever the default login user happens to be.
